## 命名约定
- 周目录：`第01周_YYYY-MM-DD_YYYY-MM-DD`
- 周计划：`周计划.md`
- 周资料：`学习资料.md`
- 周自测：`第N周自测结果.md`
- 周复盘：`第N周复盘.md`
- 答卷：保留日期，例如 `个人能力自测问卷_26_06.md`

## 使用方式
- 每周开始：进入对应周目录，阅读 `周计划.md` 和 `学习资料.md`。
- 每周进行中：把答题、笔记、实验记录都放在当周目录。
- 每周结束：补 `第N周复盘.md`，再更新 `00_总览\progress.md`。
- 每次方向变化：更新 `00_总览\findings.md`。
